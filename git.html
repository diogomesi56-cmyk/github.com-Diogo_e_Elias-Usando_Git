Git & GitHub

Janja Formulário Michelle
O que é Git?

O Git é um sistema de controle de versão distribuído, usado para registrar e acompanhar o histórico de alterações em arquivos, especialmente em códigos de programação.

O que é Github?

O GitHub é uma plataforma online de hospedagem de código-fonte e arquivos que utiliza o sistema de controle de versão Git.

Qual a diferença entre Git e Github?

O Git é o programa instalado no seu computador para guardar o histórico de alterações do seu código. Já o GitHub é o site na nuvem que armazena esses códigos e ajuda equipes a trabalhar juntas. Ou seja, o Git funciona sozinho, mas o GitHub precisa do Git.

O que é um repositório?

Um repositório é o elemento mais básico de GitHub. É um lugar onde você pode armazenar seu código, seus arquivos e o histórico de revisão de cada arquivo. Os repositórios podem ter vários colaboradores e podem ser públicos ou privados.

O que é um commit?

Um commit é o ato de salvar um conjunto de alterações de forma permanente em um sistema de controle de versão no Git

O que é um clone (git clone)?

O git clone é um comando do Git usado para criar uma cópia local de um repositório remoto existente.

Quais as vantagens de utilizar controle de versões em projetos de software?

Tem várias vantagens como: garantir a segurança do código, a organização do projeto e o trabalho em equipe eficiente.

Comentários acerca de git add e git ignore

O comando git add prepara as alterações de um projeto para o próximo commit, enquanto o arquivo git ignore avisa ao Git quais arquivos e pastas devem ser ignorados e não rastreados.
